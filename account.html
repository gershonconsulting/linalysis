⬇ Download latest extension Install guide
How to install / update (30 seconds)
  1. Click Download latest extension above and unzip it to a folder you'll keep (e.g. Documents — not a temp folder).
  2. Open chrome://extensions and turn on Developer mode (top-right).
  3. Click Load unpacked and select the unzipped folder. To update later, replace the folder's contents with a fresh download and click the ↻ reload icon on the card.
  4. Open linkedin.com/sales/ssi (signed in), then click the Linalysis icon → Sync now.

Because the extension carries a fixed key, its ID stays the same across updates, so pairing is never lost.
